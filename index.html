What I do

Build the system, then find out whether it works

A 24/7 market-data platform feeding a live inference and execution pipeline. A Bayesian sampler written from scratch because the standard tools did not apply. An on-chain wallet-intelligence engine. A fund-accounting system. A six-architecture deep-learning benchmark. In each case I built the thing, and then built the test that could have shown it was worthless.

That second half is the part I would want to be judged on. It is also why I can tell you which of these results I trust, and how much. How I work →
